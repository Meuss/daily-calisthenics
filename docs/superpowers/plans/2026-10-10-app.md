# Daily Calisthenics — Plan 2: The App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the tested domain core (`src/domain`) into the usable Android app: storage, Placement, Today, the Session player with Ratings and Adjustments, Weigh-ins, Progress, Achievements, Settings, backup, and Reminders.

**Architecture:** expo-router screens in `src/app/` stay thin. All logic lives in plain TypeScript modules with Vitest tests (`src/data/commands.ts`, `src/session/player.ts`, `src/session/finish.ts`, `src/today/todayView.ts`, `src/progress/*.ts`, `src/notifications/schedule.ts`, …). Expo native modules are only touched by small adapter files without tests (`sqlite*.ts`, `notifier.ts`, `useCues.ts`, `files.ts`) and by `.tsx` files. One React context (`AppDataProvider`) owns the event log, the settings and "today".

**Tech Stack:** pnpm, Expo SDK 57 (RN 0.86, React 19.2), expo-router 57 (`src/app`), expo-sqlite (+ `expo-sqlite/kv-store`), expo-notifications (local only), expo-keep-awake, expo-audio, react-native-svg 15.15, expo-file-system (new `File`/`Paths` API), expo-sharing, expo-document-picker, @expo/vector-icons; Vitest for logic.

**Spec:** `docs/superpowers/specs/2026-10-10-daily-calisthenics-design.md` (vocabulary `CONTEXT.md`, ADR `docs/adr/0001-derive-streak-from-event-log.md`). Builds on Plan 1 (`docs/superpowers/plans/2026-10-10-domain-core.md`); import domain code only from `src/domain` (the barrel).

## Global Constraints

- Package manager is **pnpm** (never npm/npx/yarn). Install native modules only with `pnpm expo install …` (SDK-57-compatible versions); one-off CLIs run with `pnpm dlx`. Never install `@react-navigation/*` (vendored in expo-router 57).
- Import `Tabs` from `'expo-router/js-tabs'`; `Stack`, `ThemeProvider`, `DarkTheme`, `router`, `Redirect`, `useFocusEffect`, `useLocalSearchParams` from `'expo-router'`.
- expo-file-system: use `File` / `Paths` from `'expo-file-system'`, never the legacy functions.
- Do not add the `expo-audio` config plugin (it would add RECORD_AUDIO). Do not request SCHEDULE_EXACT_ALARM; Reminders may arrive a few minutes late.
- A `.ts` file that has a `.test.ts` sibling must not import `expo*`, `react-native*` or `react` (Vitest cannot load them). Expo modules are only imported from `.tsx` files and from `src/data/sqliteEventStore.ts`, `src/data/sqliteKv.ts`, `src/notifications/notifier.ts`, `src/session/useCues.ts`, `src/backup/files.ts`.
- Colours only from `src/ui/theme.ts`; dark only, English only, kg only.
- UI copy uses the glossary terms (Routine, Session, Round, Target, Hold, Progression, Step, Rating, Adjustment, Placement, Weigh-in, Streak, Freeze, Achievement, Reminder, Short Routine, Warm-up).
- Every task ends green on: `pnpm test`, `pnpm typecheck`, `pnpm check:bundle` (Android JS bundle; `dist/` is git-ignored).
- There is no Android SDK or emulator on the dev machine. On-device behaviour is verified by the user with the checklist in Task 13.

## Review Focus

1. **Midnight while the app is open or mid-Session**: Today must roll over to the new day, and a Session started at 23:58 and finished at 00:03 counts for the day it was finished. → tests in Task 7 (`finishEvents`) and Task 3 (provider refresh is code-reviewed).
2. **App killed mid-Session**: reopening the same day offers Resume (paused); the next day the stale Session is gone. → tests in Task 4.
3. **The nudge after today's Session is done** must not fire; denied notification permission must never crash. → tests in Task 11.
4. **Corrupt or outdated stored settings / snapshot** fall back to defaults instead of crashing at launch. → tests in Tasks 2 and 4.
5. **Settings edits that break Adjustment rules** (e.g. floor + increment > ceiling) are refused with a readable message, never saved. → test in Task 12.

```ts
import type { SQLiteDatabase } from 'expo-sqlite';
import { DomainEventSchema, type DomainEvent } from '../domain';
import type { EventStore } from './eventStore';

export function createSqliteEventStore(db: SQLiteDatabase): EventStore {
  db.execSync('CREATE TABLE IF NOT EXISTS events (id INTEGER PRIMARY KEY AUTOINCREMENT, json TEXT NOT NULL);');

  const insertAll = (events: DomainEvent[]) => {
    for (const event of events) db.runSync('INSERT INTO events (json) VALUES (?)', [JSON.stringify(event)]);
  };

  return {
    all() {
      return db.getAllSync<{ json: string }>('SELECT json FROM events ORDER BY id').flatMap(({ json }) => {
        const parsed = DomainEventSchema.safeParse(JSON.parse(json));
        if (!parsed.success) console.warn('Skipping an unreadable event', json);
        return parsed.success ? [parsed.data] : [];
      });
    },
    append(events) {
      db.withTransactionSync(() => insertAll(events));
    },
    replaceAll(events) {
      db.withTransactionSync(() => {
        db.runSync('DELETE FROM events');
        insertAll(events);
      });
    },
  };
}
```

```ts
import type { ExerciseMode, LocalDate } from '../domain';

const WEEKDAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
const MINUTES_PER_DAY = 1440;

export function toMinutes(time: string): number {
  const [hours, minutes] = time.split(':').map(Number);
  return hours * 60 + minutes;
}

export function fromMinutes(minutes: number): string {
  const wrapped = ((minutes % MINUTES_PER_DAY) + MINUTES_PER_DAY) % MINUTES_PER_DAY;
  return `${String(Math.floor(wrapped / 60)).padStart(2, '0')}:${String(wrapped % 60).padStart(2, '0')}`;
}

export function formatClock(seconds: number): string {
  const total = Math.max(0, Math.round(seconds));
  return `${Math.floor(total / 60)}:${String(total % 60).padStart(2, '0')}`;
}

export function formatDay(date: LocalDate): string {
  const [year, month, day] = date.split('-').map(Number);
  const weekday = new Date(Date.UTC(year, month - 1, day)).getUTCDay();
  return `${WEEKDAYS[weekday]} ${day} ${MONTHS[month - 1]}`;
}

export function formatTarget(mode: ExerciseMode, target: number): string {
  return mode === 'reps' ? `${target} reps` : `${target} s`;
}
```

```tsx
import { openDatabaseSync } from 'expo-sqlite';
import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from 'react';
import { AppState } from 'react-native';
import { toLocalDate, type AppSettings, type DomainEvent, type LocalDate } from '../domain';
import { settingsChangeEvents } from './commands';
import type { EventStore } from './eventStore';
import type { KeyValueStore } from './kvStore';
import { loadSettings, saveSettings } from './settingsStore';
import { createSqliteEventStore } from './sqliteEventStore';
import { sqliteKeyValueStore } from './sqliteKv';

export type AppData = {
  events: DomainEvent[];
  settings: AppSettings;
  today: LocalDate;
  kv: KeyValueStore;
  append: (events: DomainEvent[]) => void;
  updateSettings: (next: AppSettings) => void;
  replaceAll: (events: DomainEvent[], settings: AppSettings) => void;
};

const AppDataContext = createContext<AppData | null>(null);

let stores: { events: EventStore; kv: KeyValueStore } | undefined;

function getStores() {
  stores ??= { events: createSqliteEventStore(openDatabaseSync('calisthenics.db')), kv: sqliteKeyValueStore };
  return stores;
}

export function AppDataProvider({ children }: { children: ReactNode }) {
  const { events: eventStore, kv } = getStores();
  const [events, setEvents] = useState(() => eventStore.all());
  const [settings, setSettings] = useState(() => loadSettings(kv));
  const [today, setToday] = useState(() => toLocalDate(new Date()));

  // "Today" rolls over at local midnight, and when the app comes back to the foreground.
  useEffect(() => {
    const refresh = () => setToday(toLocalDate(new Date()));
    const subscription = AppState.addEventListener('change', (state) => {
      if (state === 'active') refresh();
    });
    const timer = setInterval(refresh, 60_000);
    return () => {
      subscription.remove();
      clearInterval(timer);
    };
  }, []);

  const append = useCallback(
    (newEvents: DomainEvent[]) => {
      if (newEvents.length === 0) return;
      eventStore.append(newEvents);
      setEvents(eventStore.all());
    },
    [eventStore],
  );

  const updateSettings = useCallback(
    (next: AppSettings) => {
      append(settingsChangeEvents(settings, next, new Date()));
      saveSettings(kv, next);
      setSettings(next);
    },
    [append, kv, settings],
  );

  const replaceAll = useCallback(
    (nextEvents: DomainEvent[], nextSettings: AppSettings) => {
      eventStore.replaceAll(nextEvents);
      saveSettings(kv, nextSettings);
      setEvents(eventStore.all());
      setSettings(nextSettings);
    },
    [eventStore, kv],
  );

  const value = useMemo(
    () => ({ events, settings, today, kv, append, updateSettings, replaceAll }),
    [events, settings, today, kv, append, updateSettings, replaceAll],
  );

  return <AppDataContext.Provider value={value}>{children}</AppDataContext.Provider>;
}

export function useAppData(): AppData {
  const value = useContext(AppDataContext);
  if (!value) throw new Error('useAppData must be used inside AppDataProvider');
  return value;
}
```

```ts
import {
  buildSessionPlan,
  type Levels,
  type LocalDate,
  type PlanStep,
  type ProgressionId,
  type RoutineId,
  type SessionSettings,
} from '../domain';
import type { KeyValueStore } from '../data/kvStore';

export type ExerciseStep = Extract<PlanStep, { kind: 'exercise' }>;

export type PlayerState = {
  version: 1;
  routineId: RoutineId;
  startedOn: LocalDate;
  plan: PlanStep[];
  index: number;
  /** Seconds left on a timed step (Warm-up, rest, Hold); null on a reps step. */
  remaining: number | null;
  paused: boolean;
  skippedSteps: number[];
  finished: boolean;
};

export type PlayerAction =
  | { type: 'tick' }
  | { type: 'done' }
  | { type: 'skip' }
  | { type: 'pause' }
  | { type: 'resume' }
  | { type: 'replace'; state: PlayerState };

function secondsFor(step: PlanStep): number | null {
  if (step.kind === 'exercise') return step.mode === 'hold' ? step.target : null;
  return step.seconds;
}

function goTo(state: PlayerState, index: number): PlayerState {
  const step = state.plan[index];
  if (!step) return { ...state, index: state.plan.length, remaining: null, paused: false, finished: true };
  const remaining = secondsFor(step);
  if (remaining === 0) return goTo(state, index + 1);
  return { ...state, index, remaining };
}

export function startPlayer(routineId: RoutineId, levels: Levels, settings: SessionSettings, today: LocalDate): PlayerState {
  return goTo(
    {
      version: 1,
      routineId,
      startedOn: today,
      plan: buildSessionPlan(routineId, levels, settings),
      index: 0,
      remaining: null,
      paused: false,
      skippedSteps: [],
      finished: false,
    },
    0,
  );
}

export function playerReducer(state: PlayerState, action: PlayerAction): PlayerState {
  if (action.type === 'replace') return action.state;
  if (state.finished) return state;

  switch (action.type) {
    case 'pause':
      return { ...state, paused: true };
    case 'resume':
      return { ...state, paused: false };
    case 'tick':
      if (state.paused || state.remaining === null) return state;
      return state.remaining > 1 ? { ...state, remaining: state.remaining - 1 } : goTo(state, state.index + 1);
    case 'done':
      return goTo({ ...state, paused: false }, state.index + 1);
    case 'skip': {
      const isExercise = state.plan[state.index]?.kind === 'exercise';
      const skippedSteps = isExercise ? [...state.skippedSteps, state.index] : state.skippedSteps;
      return goTo({ ...state, skippedSteps, paused: false }, state.index + 1);
    }
  }
}

export function currentStep(state: PlayerState): PlanStep | undefined {
  return state.plan[state.index];
}

export function nextExercise(state: PlayerState): ExerciseStep | undefined {
  return state.plan.slice(state.index + 1).find((step): step is ExerciseStep => step.kind === 'exercise');
}

export function progressOf(state: PlayerState): { exercise: number; total: number } {
  const isExercise = (step: PlanStep) => step.kind === 'exercise';
  return {
    exercise: state.plan.slice(0, state.index + 1).filter(isExercise).length,
    total: state.plan.filter(isExercise).length,
  };
}

/** One entry per Slot that was done in at least one Round, in Slot order. */
export function ratableExercises(state: PlayerState): { progression: ProgressionId; exerciseId: string }[] {
  const seen = new Set<ProgressionId>();
  const result: { progression: ProgressionId; exerciseId: string }[] = [];
  state.plan.forEach((step, index) => {
    if (step.kind !== 'exercise' || state.skippedSteps.includes(index) || seen.has(step.progression)) return;
    seen.add(step.progression);
    result.push({ progression: step.progression, exerciseId: step.exerciseId });
  });
  return result;
}

/** Progressions skipped in at least one Round (logged on the Session for honesty). */
export function skippedProgressions(state: PlayerState): ProgressionId[] {
  const skipped = new Set<ProgressionId>();
  for (const index of state.skippedSteps) {
    const step = state.plan[index];
    if (step?.kind === 'exercise') skipped.add(step.progression);
  }
  return [...skipped];
}

const SNAPSHOT_KEY = 'session-in-progress';

export function saveSnapshot(kv: KeyValueStore, state: PlayerState | null): void {
  if (!state || state.finished) kv.remove(SNAPSHOT_KEY);
  else kv.set(SNAPSHOT_KEY, JSON.stringify(state));
}

/** A Session interrupted today can be resumed (paused); anything else is dropped. */
export function loadResumable(kv: KeyValueStore, today: LocalDate): PlayerState | null {
  const raw = kv.get(SNAPSHOT_KEY);
  if (raw === null) return null;
  try {
    const state = JSON.parse(raw) as PlayerState;
    if (state.version !== 1 || !Array.isArray(state.plan) || state.finished || state.startedOn !== today) return null;
    return { ...state, paused: true };
  } catch {
    return null;
  }
}
```

```ts
import type { PlayerState } from './player';

export type Cue = 'countdown' | 'stepStart' | 'finished';

export function cueFor(previous: PlayerState, next: PlayerState): Cue | null {
  if (next.finished && !previous.finished) return 'finished';
  if (next.index !== previous.index) return 'stepStart';
  if (next.remaining !== null && next.remaining !== previous.remaining && next.remaining <= 3) return 'countdown';
  return null;
}
```

```js
// Generates assets/sounds/beep.wav: a 0.15 s, 880 Hz sine beep (16-bit mono PCM). Run: node scripts/make-beep.mjs
import { mkdirSync, writeFileSync } from 'node:fs';

const rate = 22050;
const frequency = 880;
const samples = Math.round(rate * 0.15);
const data = Buffer.alloc(samples * 2);
for (let i = 0; i < samples; i++) {
  const fade = Math.min(1, i / 200, (samples - i) / 200);
  data.writeInt16LE(Math.round(Math.sin((2 * Math.PI * frequency * i) / rate) * 0.6 * fade * 32767), i * 2);
}

const header = Buffer.alloc(44);
header.write('RIFF', 0);
header.writeUInt32LE(36 + data.length, 4);
header.write('WAVE', 8);
header.write('fmt ', 12);
header.writeUInt32LE(16, 16);
header.writeUInt16LE(1, 20);
header.writeUInt16LE(1, 22);
header.writeUInt32LE(rate, 24);
header.writeUInt32LE(rate * 2, 28);
header.writeUInt16LE(2, 32);
header.writeUInt16LE(16, 34);
header.write('data', 36);
header.writeUInt32LE(data.length, 40);

mkdirSync('assets/sounds', { recursive: true });
writeFileSync('assets/sounds/beep.wav', Buffer.concat([header, data]));
```

```ts
    },
    [beep, mode],
  );
}
```

```ts
import {
  ACHIEVEMENTS,
  computeStreak,
  earnedAchievements,
  exerciseFor,
  newlyEarned,
  pendingAdjustments,
  toLocalDate,
  type AchievementDef,
  type Adjustment,
  type AppSettings,
  type DomainEvent,
  type ProgressionId,
  type Rating,
} from '../domain';
import { formatTarget } from '../ui/format';
import { ratableExercises, skippedProgressions, type PlayerState } from './player';

/** A Session counts for the day it is finished on. */
export function finishEvents(state: PlayerState, ratings: Partial<Record<ProgressionId, Rating>>, now: Date): DomainEvent[] {
  const at = now.toISOString();
  const date = toLocalDate(now);
  return [
    { type: 'sessionFinished', at, date, routineId: state.routineId, skipped: skippedProgressions(state) },
    ...ratableExercises(state).map(({ progression, exerciseId }): DomainEvent => ({
      type: 'ratingGiven',
      at,
      date,
      progression,
      exerciseId,
      rating: ratings[progression] ?? 'ok',
    })),
  ];
}

export type SessionOutcome = { streak: number; newAchievements: AchievementDef[]; adjustments: Adjustment[] };

export function sessionOutcome(before: DomainEvent[], added: DomainEvent[], settings: AppSettings, now: Date): SessionOutcome {
  const today = toLocalDate(now);
  const after = [...before, ...added];
  const fresh = new Set(newlyEarned(earnedAchievements(before, today), earnedAchievements(after, today)).map((a) => a.id));
  return {
    streak: computeStreak(after, today).current,
    newAchievements: ACHIEVEMENTS.filter((a) => fresh.has(a.id)),
    adjustments: pendingAdjustments(after, settings.adjustments),
  };
}

export function describeAdjustment({ progression, direction, from, to }: Adjustment): string {
  const target = exerciseFor(progression, to.step);
  const amount = formatTarget(target.mode, to.target);
  if (to.step !== from.step) return `${direction === 'up' ? 'Level up' : 'Step back'}: ${target.name} × ${amount}`;
  return `${target.name}: ${formatTarget(target.mode, from.target)} → ${amount}`;
}
```

```ts
import {
  EXERCISES,
  ROUTINES,
  buildSessionPlan,
  computeStreak,
  deriveLevels,
  deriveWeighIns,
  estimateSeconds,
  nextRoutineId,
  type AppSettings,
  type DomainEvent,
  type ExerciseMode,
  type LocalDate,
} from '../domain';

export type TodayView = {
  streak: number;
  best: number;
  freezes: number;
  doneToday: boolean;
  routineName: string;
  preview: { exerciseId: string; name: string; mode: ExerciseMode; target: number }[];
  estimatedMinutes: number;
  weighInToday: number | null;
  resumable: boolean;
};

export function todayView(events: DomainEvent[], settings: AppSettings, today: LocalDate, resumable: boolean): TodayView {
  const streak = computeStreak(events, today);
  const routineId = nextRoutineId(events);
  const plan = buildSessionPlan(routineId, deriveLevels(events), settings.session);
  const preview = plan.flatMap((step) =>
    step.kind === 'exercise' && step.round === 1
      ? [{ exerciseId: step.exerciseId, name: EXERCISES[step.exerciseId].name, mode: step.mode, target: step.target }]
      : [],
  );
  return {
    streak: streak.current,
    best: streak.best,
    freezes: streak.freezesAvailable,
    doneToday: events.some((e) => e.type === 'sessionFinished' && e.date === today),
    routineName: ROUTINES[routineId].name,
    preview,
    estimatedMinutes: Math.round(estimateSeconds(plan) / 60),
    weighInToday: deriveWeighIns(events).find((w) => w.date === today)?.kg ?? null,
    resumable,
  };
}
```

```ts
import { addDays, daysBetween, movingAverage7, type LocalDate, type WeighIn } from '../domain';

export const CHART_DAYS = 60;

export type ChartPoint = { date: LocalDate; x: number; y: number };
export type ChartGeometry = { raw: ChartPoint[]; average: string; minKg: number; maxKg: number };

/** Raw Weigh-ins as dots and the 7-day average as a line, over the `days` ending today. */
export function chartGeometry(weighIns: WeighIn[], today: LocalDate, days: number, width: number, height: number, padding = 16): ChartGeometry | null {
  const from = addDays(today, -(days - 1));
  const inWindow = (w: WeighIn) => w.date >= from && w.date <= today;
  const raw = weighIns.filter(inWindow);
  if (raw.length === 0) return null;

  const average = movingAverage7(weighIns).filter(inWindow);
  const values = [...raw, ...average].map((w) => w.kg);
  const minKg = Math.min(...values) - 0.5;
  const maxKg = Math.max(...values) + 0.5;
  const x = (date: LocalDate) => padding + (daysBetween(from, date) / (days - 1)) * (width - 2 * padding);
  const y = (kg: number) => padding + ((maxKg - kg) / (maxKg - minKg)) * (height - 2 * padding);

  return {
    raw: raw.map((w) => ({ date: w.date, x: x(w.date), y: y(w.kg) })),
    average: average.map((w) => `${x(w.date)},${y(w.kg)}`).join(' '),
    minKg,
    maxKg,
  };
}
```

```ts
import { addDays, mondayOf, type DayRecord, type DayStatus, type LocalDate } from '../domain';

export type CalendarCell = { date: LocalDate; status: DayStatus | 'none' | 'future' };

export function calendarWeeks(days: DayRecord[], today: LocalDate, weeks = 5): CalendarCell[][] {
  const statusByDate = new Map(days.map((day) => [day.date, day.status]));
  const firstMonday = mondayOf(addDays(today, -7 * (weeks - 1)));
  return Array.from({ length: weeks }, (_, week) =>
    Array.from({ length: 7 }, (_, weekday) => {
      const date = addDays(firstMonday, week * 7 + weekday);
      const status = date > today ? 'future' : (statusByDate.get(date) ?? 'none');
      return { date, status };
    }),
  );
}
```

```ts
import { ACHIEVEMENTS, earnedAchievements, type AchievementDef, type DomainEvent, type LocalDate } from '../domain';

export type AchievementRow = { def: AchievementDef; earnedOn: LocalDate | null };

export function achievementRows(events: DomainEvent[], today: LocalDate): AchievementRow[] {
  const earned = earnedAchievements(events, today);
  const earnedOn = new Map(earned.map((a) => [a.id, a.earnedOn]));
  const byId = new Map(ACHIEVEMENTS.map((def) => [def.id, def]));
  const earnedRows = [...earned].reverse().flatMap((a) => {
    const def = byId.get(a.id);
    return def ? [{ def, earnedOn: a.earnedOn }] : [];
  });
  const lockedRows = ACHIEVEMENTS.filter((def) => !earnedOn.has(def.id)).map((def) => ({ def, earnedOn: null }));
  return [...earnedRows, ...lockedRows];
}
```

```ts
import { toLocalDate, type ReminderSettings } from '../domain';
import { toMinutes } from '../ui/format';

export type ScheduledReminder = { id: string; title: string; body: string } & (
  | { kind: 'daily'; hour: number; minute: number }
  | { kind: 'date'; date: Date }
);

export const NUDGE_DAYS = 7;

export function reminderPlan(reminder: ReminderSettings, doneToday: boolean, now: Date): ScheduledReminder[] {
  const plan: ScheduledReminder[] = [];

  if (reminder.enabled) {
    const minutes = toMinutes(reminder.time);
    plan.push({
      id: 'daily-reminder',
      kind: 'daily',
      hour: Math.floor(minutes / 60),
      minute: minutes % 60,
      title: 'Time to move',
      body: 'Your 12-minute Routine is ready.',
    });
  }

  if (reminder.nudgeEnabled) {
    const minutes = toMinutes(reminder.nudgeTime);
    for (let offset = 0; offset < NUDGE_DAYS; offset++) {
      const date = new Date(now.getFullYear(), now.getMonth(), now.getDate() + offset, Math.floor(minutes / 60), minutes % 60);
      if (offset === 0 && (doneToday || date <= now)) continue;
      plan.push({
        id: `nudge-${toLocalDate(date)}`,
        kind: 'date',
        date,
        title: 'Still time today',
        body: 'Even the Short Routine keeps your Streak alive.',
      });
    }
  }

  return plan;
}
```

```ts
import * as Notifications from 'expo-notifications';
import type { ScheduledReminder } from './schedule';

const CHANNEL_ID = 'reminders';

Notifications.setNotificationHandler({
  handleNotification: async () => ({ shouldShowBanner: true, shouldShowList: true, shouldPlaySound: true, shouldSetBadge: false }),
});

async function ensureChannel(): Promise<void> {
  await Notifications.setNotificationChannelAsync(CHANNEL_ID, { name: 'Reminders', importance: Notifications.AndroidImportance.HIGH });
}

/** Android 13+ only shows the permission prompt once a channel exists. */
export async function ensureNotificationPermission(): Promise<boolean> {
  await ensureChannel();
  const current = await Notifications.getPermissionsAsync();
  if (current.granted) return true;
  return (await Notifications.requestPermissionsAsync()).granted;
}

/** Replaces every scheduled notification with `plan`. Does nothing without permission. */
export async function syncReminders(plan: ScheduledReminder[]): Promise<void> {
  const permission = await Notifications.getPermissionsAsync();
  if (!permission.granted) return;
  await ensureChannel();
  await Notifications.cancelAllScheduledNotificationsAsync();
  for (const reminder of plan) {
    await Notifications.scheduleNotificationAsync({
      identifier: reminder.id,
      content: { title: reminder.title, body: reminder.body },
      trigger:
        reminder.kind === 'daily'
          ? { type: Notifications.SchedulableTriggerInputTypes.DAILY, hour: reminder.hour, minute: reminder.minute, channelId: CHANNEL_ID }
          : { type: Notifications.SchedulableTriggerInputTypes.DATE, date: reminder.date, channelId: CHANNEL_ID },
    });
  }
}
```

```ts
import * as DocumentPicker from 'expo-document-picker';
import { File, Paths } from 'expo-file-system';
import * as Sharing from 'expo-sharing';

export async function shareBackup(fileName: string, contents: string): Promise<void> {
  const file = new File(Paths.cache, fileName);
  file.create({ overwrite: true });
  file.write(contents);
  if (!(await Sharing.isAvailableAsync())) throw new Error('Sharing is not available on this phone.');
  await Sharing.shareAsync(file.uri, { mimeType: 'application/json', dialogTitle: 'Export backup' });
}

/** Some Android file providers report JSON as text or octet-stream, so accept any file and let parseBackup judge it. */
export async function pickBackupText(): Promise<string | null> {
  const result = await DocumentPicker.getDocumentAsync({ type: ['application/json', 'text/plain', '*/*'], copyToCacheDirectory: true });
  if (result.canceled) return null;
  return new File(result.assets[0].uri).textSync();
}
```

```md
# Daily Calisthenics

**A 12-minute bodyweight routine every morning — no equipment, no account, no excuses.**

Daily Calisthenics is a small, free Android app that tells you exactly what to do each morning: a short guided circuit with simple illustrations, reps or a timer for every move, and a Streak that forgives the occasional bad day.

<!-- screenshots -->

## Features

- **Guided Sessions**: Warm-up, then 3 Rounds of 4 Exercises with countdowns, beeps and vibration. About 12 minutes.
- **Starts where you are**: three questions place you on each Progression (wall push-ups to diamond push-ups, and more). Floor and a chair are all you need.
- **Gets harder as you do**: rate each Exercise *too easy / OK / too hard* and the app suggests more reps or the next Step.
- **Bad day? Short Routine**: a 3-minute version still keeps your Streak alive, and a weekly Freeze covers a missed day.
- **Weigh-ins**: one tap after your Session, with a 7-day average chart.
- **Achievements and Reminders** to keep you coming back.
- **Private**: everything stays on your phone. Export a backup file whenever you like.

## Install

Daily Calisthenics isn't on the Play Store. To try it today:

1. Install **Expo Go for SDK 57** on your Android phone (linked from https://expo.dev/go).
2. On a computer with Node.js and pnpm: `git clone https://github.com/Meuss/daily-calisthenics && cd daily-calisthenics && pnpm install && pnpm start`
3. Scan the QR code with Expo Go (same Wi-Fi, or `pnpm start --tunnel`).

A downloadable APK on the [Releases](https://github.com/Meuss/daily-calisthenics/releases) page is planned.
```

```md
# On-device checklist

Run through this on a real Android phone (Expo Go or an installed APK). There is no emulator in CI.

## First run
- [ ] Fresh install opens on Placement; tabs are not reachable until it's saved.
- [ ] Saving Placement asks for notification permission and lands on Today with "Push & core" (or the chosen Rotation start).

## Session
- [ ] Start → Warm-up counts down with beeps/vibration in the last 3 s and moves on by itself.
- [ ] Reps Exercise waits for Done; Hold counts down; rest shows "Up next" with its illustration.
- [ ] Pause stops the clock; screen stays awake (if enabled).
- [ ] Kill the app mid-Session, reopen the same day → Today offers Resume, Resume continues paused at the same step.
- [ ] Stop → "Do the Short Routine instead" starts a 1-Round Session without Warm-up; "Stop and go back" does not count.
- [ ] Finish → Ratings (default OK) → summary shows the Streak; after two "Too easy" in a row, an Adjustment is suggested; Accept updates the Target on Progress.
- [ ] Weigh-in prompt appears after the Session when none was logged today.

## Today, Progress, Achievements
- [ ] After a Session, Today shows "Done for today" and the next Routine is the next in the Rotation.
- [ ] Weigh-in: log with a comma decimal, backfill yesterday with ‹, edit and delete from Progress.
- [ ] Chart shows dots and the 7-day average line; calendar shows done/frozen/missed days.
- [ ] 3 days in a row earns "3-day Streak" on the Achievements tab.

- [ ] Nudge arrives at its time on a day without a Session, and not on a day with one.

- [ ] Export backup → share sheet; Reset all data → back to Placement; Import that backup → history restored.
```
