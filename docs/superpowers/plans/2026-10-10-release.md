# Daily Calisthenics — Plan 3: Signed APK Releases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `v1.2.3` tag builds a signed release APK on GitHub Actions and attaches it to a GitHub Release, with a proper icon, a dark splash and a clean notification icon, so the app can be installed (and updated in place) on a phone.

**Architecture:** No Expo/EAS account. The workflow runs `expo prebuild` (the `android/` folder stays generated, never committed) and `./gradlew assembleRelease`. A small committed config plugin teaches the generated `build.gradle` to sign with a release key passed through environment variables; `app.config.js` stamps versionName/versionCode from the tag. Icons are drawn in code and rendered with resvg.

**Tech Stack:** GitHub Actions (ubuntu-24.04, JDK 17, Android SDK preinstalled, NDK 27.1.12297006 installed by the workflow), Expo SDK 57 prebuild + Gradle 9.3.1, `@resvg/resvg-js`, pnpm 12, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-10-daily-calisthenics-design.md` (section *Platform & distribution*). Builds on Plans 1 and 2.

## Global Constraints

- pnpm only (never npm/npx/yarn). Native modules via `pnpm expo install`.
- Package `com.meuss.calisthenics`, display name `Daily Calisthenics`, Android only, dark only.
- `android/` is generated by prebuild and stays git-ignored; never hand-edit or commit it. Native changes go through `app.json` / `app.config.js` / config plugins.
- Release tags look like `v1.2.3`; versionName = `1.2.3`, versionCode = `major*10000 + minor*100 + patch`; minor and patch must be below 100.
- The signing key never enters the repo, logs or chat. It lives in four GitHub secrets (`RELEASE_KEYSTORE_BASE64`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`) and in the owner's password manager only. Certificate subject: `CN=Daily Calisthenics, O=Meuss`.
- A release build without the signing secrets must fail; it must never publish a debug-signed APK.
- Colours: background `#0B0F14`, accent `#4ADE80` (from `src/ui/theme.ts`).
- Every code task ends green on `pnpm test && pnpm typecheck && pnpm check:bundle`.

## Review Focus

1. **A tag build with missing or wrong secrets** must fail before publishing, never ship an APK signed with the debug key. → secret check + certificate check steps in Task 4, verified in Task 6.
2. **Every release must install over the previous one**: same certificate on every build, strictly increasing versionCode. → tests in Task 1, certificate comparison in Task 6.
3. **A future Expo template change** that breaks the signing plugin's text patterns must fail loudly, not silently fall back to debug signing. → test in Task 2.
4. **First launch looks right**: dark splash (not the white placeholder grid), dark system bars, the new icon in the launcher. → prebuild checks in Task 3, emulator check in Task 6.
5. **The Reminder notification** shows a clean green/white silhouette in the status bar, not a white square, and actually fires in the real build. → Task 3 config, Task 6 emulator check.

```js
// Turns a release tag into the Android versionName/versionCode. Used by .github/workflows/release.yml.
import { fileURLToPath } from 'node:url';

/** 'v1.2.3' → { name: '1.2.3', code: 10203 }. Minor and patch stay below 100 so codes always increase. */
export function versionFromTag(tag) {
  const match = /^v(\d+)\.(\d+)\.(\d+)$/.exec(tag);
  if (!match) throw new Error(`Release tags look like v1.2.3, got "${tag}"`);
  const [major, minor, patch] = match.slice(1).map(Number);
  if (minor > 99 || patch > 99) throw new Error(`Minor and patch must be below 100, got "${tag}"`);
  const code = major * 10000 + minor * 100 + patch;
  if (code === 0) throw new Error('versionCode must be above 0; start at v0.0.1 or v1.0.0');
  return { name: `${major}.${minor}.${patch}`, code };
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const { name, code } = versionFromTag(process.argv[2] ?? '');
  console.log(`APP_VERSION=${name}`);
  console.log(`APP_VERSION_CODE=${code}`);
}
```

- [ ] **Step 3: Implement `tooling/withReleaseSigning.js`**

```js
// Expo config plugin: sign release builds with the key passed in RELEASE_* environment variables (see release.yml).
const { withAppBuildGradle } = require('expo/config-plugins');

const RELEASE_CONFIG = `
        release {
            if (System.getenv('RELEASE_STORE_FILE')) {
                storeFile file(System.getenv('RELEASE_STORE_FILE'))
                storePassword System.getenv('RELEASE_STORE_PASSWORD')
                keyAlias System.getenv('RELEASE_KEY_ALIAS')
                keyPassword System.getenv('RELEASE_KEY_PASSWORD')
            }
        }`;

function applyReleaseSigning(gradle) {
  if (gradle.includes('RELEASE_STORE_FILE')) return gradle;

  const withConfig = gradle.replace(/(signingConfigs\s*\{\s*debug\s*\{[^}]*\})/, `$1${RELEASE_CONFIG}`);
  const withBuildType = withConfig.replace(
    /(buildTypes\s*\{[\s\S]*?release\s*\{[^}]*?)signingConfig signingConfigs\.debug/,
    "$1signingConfig System.getenv('RELEASE_STORE_FILE') ? signingConfigs.release : signingConfigs.debug",
  );

  if (withConfig === gradle || withBuildType === withConfig) {
    throw new Error('withReleaseSigning: android/app/build.gradle no longer matches the expected template');
  }
  return withBuildType;
}

function withReleaseSigning(config) {
  return withAppBuildGradle(config, (cfg) => {
    cfg.modResults.contents = applyReleaseSigning(cfg.modResults.contents);
    return cfg;
  });
}

module.exports = withReleaseSigning;
module.exports.applyReleaseSigning = applyReleaseSigning;
```

```js
// Draws the app's icons in code and renders them to PNG. Run: pnpm icons
import { Resvg } from '@resvg/resvg-js';
import { writeFileSync } from 'node:fs';

const BACKGROUND = '#0B0F14';
const ACCENT = '#4ADE80';
const WHITE = '#FFFFFF';

// PUSH_UP_UP from src/illustrations/poses.ts, on its 120×100 canvas, plus a ground line.
const POSE = { head: [96, 62], neck: [88, 68], hip: [54, 80], elbow: [88, 80], hand: [88, 92], knee: [37, 86], foot: [20, 92] };
const FIGURE_CENTRE = [60, 75];
const FIGURE_WIDTH = 100;

const points = (...list) => list.map(([x, y]) => `${x},${y}`).join(' ');

/** The figure centred on a square canvas, `share` of its width (adaptive icons only show the middle ~61%). */
function figure(size, color, { share = 0.6, ground = true } = {}) {
  const scale = (size * share) / FIGURE_WIDTH;
  const tx = size / 2 - FIGURE_CENTRE[0] * scale;
  const ty = size / 2 - FIGURE_CENTRE[1] * scale;
  return `<g transform="translate(${tx} ${ty}) scale(${scale})" fill="none" stroke="${color}" stroke-width="7" stroke-linecap="round" stroke-linejoin="round">
    ${ground ? '<line x1="10" y1="96" x2="110" y2="96" stroke-width="3.5" opacity="0.45"/>' : ''}
    <polyline points="${points(POSE.neck, POSE.hip)}"/>
    <polyline points="${points(POSE.neck, POSE.elbow, POSE.hand)}"/>
    <polyline points="${points(POSE.hip, POSE.knee, POSE.foot)}"/>
    <circle cx="${POSE.head[0]}" cy="${POSE.head[1]}" r="7"/>
  </g>`;
}

function writePng(file, size, body, background) {
  const fill = background ? `<rect width="${size}" height="${size}" fill="${background}"/>` : '';
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="${size}" height="${size}" viewBox="0 0 ${size} ${size}">${fill}${body}</svg>`;
  writeFileSync(file, new Resvg(svg, { fitTo: { mode: 'width', value: size } }).render().asPng());
  console.log(`wrote ${file} (${size}×${size})`);
}

writePng('assets/icon.png', 1024, figure(1024, ACCENT, { share: 0.7 }), BACKGROUND);
writePng('assets/android-icon-foreground.png', 1024, figure(1024, ACCENT));
writePng('assets/android-icon-monochrome.png', 1024, figure(1024, WHITE));
writePng('assets/splash-icon.png', 1024, figure(1024, ACCENT, { share: 0.8 }));
writePng('assets/notification-icon.png', 96, figure(96, WHITE, { share: 0.85, ground: false }));
```

- [ ] **Step 2: Create `.github/workflows/release.yml`**

```yaml
name: Release APK

on:
  push:
    tags: ['v*.*.*']
  workflow_dispatch:

permissions:
  contents: write

concurrency:
  group: release-${{ github.ref }}
  cancel-in-progress: false

jobs:
  apk:
    runs-on: ubuntu-24.04
    timeout-minutes: 60
    env:
      KEYSTORE_BASE64: ${{ secrets.RELEASE_KEYSTORE_BASE64 }}
      RELEASE_STORE_PASSWORD: ${{ secrets.RELEASE_STORE_PASSWORD }}
      RELEASE_KEY_ALIAS: ${{ secrets.RELEASE_KEY_ALIAS }}
      RELEASE_KEY_PASSWORD: ${{ secrets.RELEASE_KEY_PASSWORD }}
      NDK_VERSION: 27.1.12297006
      BUILD_TOOLS: 36.0.0
    steps:
      - uses: actions/checkout@v7

      - name: Refuse to build without the signing key
        run: |
          for name in KEYSTORE_BASE64 RELEASE_STORE_PASSWORD RELEASE_KEY_ALIAS RELEASE_KEY_PASSWORD; do
            if [ -z "${!name}" ]; then echo "::error::Missing signing secret for $name"; exit 1; fi
          done

      - name: Version from tag
        run: |
          if [[ "$GITHUB_REF" == refs/tags/* ]]; then
            node tooling/version.mjs "$GITHUB_REF_NAME" >> "$GITHUB_ENV"
          else
            echo "APP_VERSION=0.0.${GITHUB_RUN_NUMBER}-test" >> "$GITHUB_ENV"
          fi

      - uses: pnpm/setup@v3
        with:
          version: 12.5.1
          runtime: node@24
          cache: true

      - uses: actions/setup-java@v6
        with:
          distribution: temurin
          java-version: '17'

      - uses: gradle/actions/setup-gradle@v6

      - name: Install the Android NDK
        run: |
          SDKMANAGER="$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager"
          yes | "$SDKMANAGER" --licenses > /dev/null
          "$SDKMANAGER" "ndk;$NDK_VERSION" > /dev/null

      - run: pnpm install --frozen-lockfile
      - run: pnpm test
      - run: pnpm typecheck

      - name: Generate the Android project
        run: pnpm expo prebuild --platform android --no-install

      - name: Build the signed APK
        run: |
          printf '%s' "$KEYSTORE_BASE64" | base64 -d > "$RUNNER_TEMP/release.keystore"
          export RELEASE_STORE_FILE="$RUNNER_TEMP/release.keystore"
          cd android
          ./gradlew assembleRelease --no-daemon
          rm -f "$RELEASE_STORE_FILE"

      - name: Check it is signed with the release key
        run: |
          APK=android/app/build/outputs/apk/release/app-release.apk
          "$ANDROID_HOME/build-tools/$BUILD_TOOLS/apksigner" verify --print-certs "$APK" | tee certs.txt
          grep -q "CN=Daily Calisthenics" certs.txt || { echo "::error::APK is not signed with the release key"; exit 1; }
          mv "$APK" "daily-calisthenics-$APP_VERSION.apk"

      - uses: actions/upload-artifact@v7
        with:
          name: daily-calisthenics-apk
          path: daily-calisthenics-*.apk

      - name: Publish the GitHub Release
        if: startsWith(github.ref, 'refs/tags/')
        env:
          GH_TOKEN: ${{ github.token }}
        run: gh release create "$GITHUB_REF_NAME" daily-calisthenics-*.apk --title "Daily Calisthenics $APP_VERSION" --generate-notes
```
